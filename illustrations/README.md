# Illustrations

Seven standalone pieces composed from the assets that already exist in
`images/motifs/` and `images/icons/` — the plume head, the pyre, the smoke,
the whirlwinds, the wind gust and the six cameras — so the villain and its
world keep a life outside the genealogy page. Nothing was drawn new except the
two LEDs and the REC on the glasses.

Every file is **painted**: hex colours baked in, no CSS classes, no `var()`.
That is the styleguide's own rule for anything that travels — a class-driven
SVG renders solid black through `<img>`, in Keynote, in a sticker printer's
RIP. These work anywhere an SVG works.

`02` and `05` also come as `-transparent` variants (no orange rectangle) for
placing on other surfaces. Every SVG has a PNG at native size; the sticker
shapes also have `@2x` PNGs (2160 px / 1600 px).

## A new asset

`images/motifs/wind-gust.svg` is new to the repo. The gust — the pink
streamlines that break into curls — only ever existed inside the `<defs>` of
the old `genealogy.html`, as `#gm-wind`, painted by `genealogy.css` through
CSS variables. The rebuilt genealogy page does not carry it, so without this
file it would have left the repository with that commit. It is saved here as
a painted standalone (30 KB, viewBox cropped to the ink) and is what `04`,
`05` and the build script draw from.

## Regenerating

```
python3 scripts-dev/build-illustrations.py
```

From the repo root. Writes every SVG into `illustrations/`. Positions, sizes
and which piece goes where are all in that file, one function per
illustration, with the geometry reasoning in comments — the glasses are
scaled so their lens centres land on the head's eye centres, the gust is
placed by the measured source point of its streams, and so on.
`scripts-dev/illustrations_lib.py` holds the helpers: `embed()` places any
motif file and namespaces its ids so two files with the same `#fbody` cannot
collide; `paint_camera()` turns a class-driven camera icon into a painted one
by applying the `cameras.css` rules as attributes, with `live` / `spent`
lens states.

PNGs are not regenerated by the script — render the SVGs with whatever you
prefer. They were made here with headless Chromium at 1× and 2×.

## Notes for use

- **Fonts.** The only text in the set is the `REC` on `02`. It asks for
  JetBrains Mono and falls back to the system monospace; three capitals look
  fine in either. Everything else is geometry.
- **Cropping.** `01` and `07` are compositions with a horizon; crop from the
  top, not the bottom, or the pyre loses its ground. `03` crops freely from
  the top.
- **Colour.** All from `tokens.css`: `#f26a1b` orange, `#072e26` deep green,
  `#ff5f8f` pink, `#f0c24a` yellow, `#fff1cf` cream, `#0a0a08` ink. The pyre
  and smoke files carry the older v1 smoke ramp (`#031f19 #04302a #063f32
  #0a4d3a`), exactly as the styleguide documents them as an accepted anomaly.
- **The pink rule holds.** Pink never sits bare on orange as a shape: in `04`
  and `05` the gust and whirlwind are ink-outlined, which is how the source
  files draw them; in `05` the spent pupils sit on deep green.
