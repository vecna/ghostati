# images/projects

This folder contains the local publication images used by the generated complementary-projects table at `/projects/`. Filenames match project slugs and use a consistent 3:2 presentation crop. The authoritative source URL, creator credit, alt text, and rights-review status live beside each project in `projects/PROJECTS.json`.

These are third-party documentary images, not Ghostmaxxing-owned illustrations. Inclusion in the repository does not change their copyright. Before deploying an image, review the recorded rights status and obtain permission or establish an appropriate quotation basis. Replace an asset without changing its filename when permission supplies a higher-quality or differently cropped version, then recheck its alt text and credit.
